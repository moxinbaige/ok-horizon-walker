# 本地反馈包

每日任务结束时，如果本轮保存了错误记录（包括成功返回首页后跳过的步骤），助手会询问是否生成反馈包。运行过程中不弹出此提示，每轮只询问一次。主动停止且没有错误记录时不询问，重新打开助手也不会重复询问历史错误。

也可在「运行概览」点击「生成最近一次运行反馈包」。仅在没有任务运行且最近一次运行有错误记录时可用。

生成前可预览截图、取消勾选个别截图；截图缺失时仍可生成记录包。取消选择保存位置不会写入文件。默认保存到本助手目录的 `docs/feedback-日期时间.zip`，完成后可打开所在文件夹。

压缩包包含本轮摘要、结构化运行记录（含错误堆栈及动作记录），以及所选错误/恢复截图。不收集整个日志目录、历史截图、设置文件或凭据，也不自动上传。文本中的项目路径、其他 Windows 本机及网络路径会被替换；截图保持原样，请自行检查昵称、账号等信息后再分享。

便携版使用自己的记录和截图。新运行会覆盖「最近一次运行」入口；需要反馈的问题请及时打包保留。
